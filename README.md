# ChartTart

本机多通道波形浏览与分析工具。支持横移和缩放、分段划选、逐搏 RR、双光标 PR 测量，以及把结果写入数据表。

[查看 v1.2.1 发布说明](https://github.com/MerlinScarborough/ChartTart/releases/tag/v1.2.1) · [下载 Windows 便携试用版](https://github.com/MerlinScarborough/ChartTart/releases/download/v1.2.1/ChartTart-1.2.1-trial-win64.zip)

## 开始使用

1. 在装有 Microsoft Edge WebView2 Runtime 的 Windows 10 或 11（64 位）上，完整解压 ZIP。
2. 在解压目录打开 `ChartTart.exe`。Python 运行环境已随包提供。
3. 点击「波形练习」，或打开随包的 `ChartTart-5min.adicht`，跟着界面上的高亮提示练习。

## 使用条款

软件按随包的试用版条款提供，具体内容见包内《开始使用》。第三方组件许可随包附带。ChartTart 与 ADInstruments 无隶属关系。
